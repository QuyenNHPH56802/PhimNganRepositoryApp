# Golden Dataset

## Purpose

The golden dataset (`datasets/golden/`) is the source of truth for benchmark
metrics. It is small on purpose (Phase 5 ships 5 seed sentences across 5
domains) so it can be reviewed by hand and expanded deterministically.

## Layout

```
datasets/golden/
  manifest.yaml
  zh-vi/
    sentences.jsonl        # Pydantic GoldenSentence records
    transcripts/*.txt      # raw source Chinese (UTF-8)
    reference/*.vi.txt     # reference Vietnamese translation
    subtitles/*.srt        # subtitle template (CPS heuristic)
    audio/*.wav            # optional fixtures (off by default)
  ocr/
    frames/*.png           # burned-subtitle frame
    frames/*.json          # expected detections (bboxes)
  text-removal/
    frames/*.png           # source frame
    frames/*.expected.png  # reference inpainted frame
```

## License + provenance

`manifest.yaml` declares:

```yaml
name: translator-zh-vi-golden-v0
license: CC-BY-SA-4.0
sources:
  - contributor: ops@team
    source: in-house
  - contributor: synthetic
    source: synthetic
```

Per-record licenses live in `sentences.jsonl`. Contributors MUST pick one
of:

| License | When |
|---------|------|
| `CC-BY-SA-4.0` | Human-written translations |
| `CC-BY-4.0` | Third-party translations with permission |
| `CC0` | Synthetic expansions generated by `build_golden.py` |

The CI rejects any new record that lacks `provenance.contributor`.

## Adding new sentences

```bash
# 1. Add transcripts/raw/zh_001.txt and vi_001.txt (UTF-8, line-aligned)
# 2. Run the builder:
python scripts/build_golden.py \
    --source datasets/golden/raw/zh_001.txt \
    --reference datasets/golden/raw/vi_001.txt \
    --out datasets/golden/zh-vi \
    --domain vlog --speaker-gender x \
    --tags manual,seed
```

## Contributing audio

We do not auto-collect audio. Drop files into
`datasets/golden/zh-vi/audio/<line_id>.wav` and update `sentences.jsonl`
to reference them. Avoid copyrighted material; if it is third-party, link
the license in the manifest.

## Voice profile + consent

Any voice profile derived from audio in this dataset is subject to the
consent workflow (`docs/security.md`). Use the `consent_status` field on
`voice_profiles` to track the lifecycle.
