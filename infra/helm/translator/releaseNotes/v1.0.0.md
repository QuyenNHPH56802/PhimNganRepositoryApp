# v1.0.0 — Initial stable release

Chart version: 1.0.0
App version: 1.0.0

## Highlights

- API + Worker + Web in a single chart, opt-out via `api.enabled`,
  `worker.enabled`, `web.enabled`.
- `values.schema.json` enforces required fields.
- Multi-arch Docker images (amd64, arm64) referenced via `image.repository`
  + `image.tag`.

## Breaking changes

None — this is the first chart release.

## Upgrade notes

Fresh install only; upgrade from v0.x requires uninstall + reinstall.
